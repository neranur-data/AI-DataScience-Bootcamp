# NumPy & Pandas – Data Analysis Projects

This folder contains Python data analysis exercises and projects completed as part of my Data Science & AI Bootcamp.

## Projects

### 1. Categorical Variable Visualization

**File:** `katagoric-degisken-gorsellestirme.py`

Exploratory data visualization using the Titanic dataset.

- Load a dataset using Seaborn.
- Explore categorical and numerical variables.
- Create a boxplot to visualize fare distribution.
- Practice basic data visualization with Matplotlib.

**Libraries:** Pandas, Seaborn, Matplotlib

### 2. Rule-Based Customer Classification

**File:** `kural_tabanli_siniflandirma_calismasi.py`

Customer segmentation using the Persona dataset.

- Explore customer and transaction data.
- Analyze revenue by country and device type.
- Calculate average revenue across customer groups.
- Categorize customers into age groups.
- Create rule-based customer personas.
- Segment customer profiles into four groups (A, B, C, D) based on average revenue.
- Examine example customer profiles and export segmentation results.

**Libraries:** Pandas

**Dataset:** `persona.csv`
